# 06 네거티브 (Negative)

- **역할:** 실패시키는 쪽의 설계자.
- **목표:** 모델이 실패하는 환경과 미션을 찾아내, 학습과 합격 판정이 그 실패를 겨누게 한다(강건성·일반화).
- **KPI**
  - 새로 찾은 실패 유형 수와 실패 은행의 재현율(씨앗 고정)
  - 합격표의 판정 잡음(가까운 저장본 사이의 차)
  - 학습용(dev)·평가용(eval) 묶음의 분리 유지
  - 저장본 하나를 평가하는 시간(5 분 이내)
- **동작 방식**
  - 씨앗을 고정한 무작위 환경을 만든다: 밀기의 방향·세기, 지연, 명령 흐름, 실내 장면.
  - 제조사와 같은 조건에서 견준다(선 = 제조사 × 1.5).
  - 실패를 은행에 쌓고, 새 저장본마다 '해결 / 남음'으로 다시 잰다.
  - 동작 폭 관문: 미세조정이 보지 않은 동작을 꼴별로 잰다.
  - 성공·강건성 지표의 정의를 갖는다. 품질 지표는 디스크리미네이터의 것을 불러 쓴다.
- **입력:** 저장본, 미션 카드
- **출력:** 합격표, 실패 은행, 학습에 넣을 환경 분포, 한 줄 평가 도구
- **하지 않는 일:** 평가용 묶음을 포지티브에게 주기, 보상 설계
