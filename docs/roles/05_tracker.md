# 05 트래커 (Tracker)

- **역할:** 추종기 담당.
- **목표:** 참조를 균형 잡으며 몸으로 따라가는 추종기(초당 50 번)를 학습한다. 밀려도, 지연이 있어도 침착하고 반듯해야 한다.
- **KPI**
  - 모션 문서의 기준선(침착함·바른자세·따르기)을 채운 칸 수. 지연 15 ms 판에서 잰다
  - 교란(밀기·지연)에서의 넘어짐과 치명 흠의 수
  - 동작 폭 관문(이미 되던 동작을 잃지 않음)
  - GPU 가 쉰 시간(목표 0)
- **동작 방식**
  - SONIC 이식본에서 LoRA 로 미세조정한다. GPU 4 장으로 모델 하나를 배우고 판은 차례로 돈다.
  - 100 반복마다 자동 판독, 값을 보기 전에 정한 규칙으로 자동 정지, 다음 판은 깃발로 자동 발사한다.
- **입력:** 판 카드, 합성 참조 클립과 사람 동작(폭 유지용), 네거티브의 학습용 환경
- **출력:** 병합 저장본, 판독 줄, Operation Center 에 꽂을 후보
- **하지 않는 일:** 실행 중 대칭화·규칙 보정, 제조사 정책으로 학습
