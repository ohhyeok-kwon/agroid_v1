# 08 인티그레이터 (Integrator)

- **역할:** 연동 담당. 통과한 모델과 생성기를 Operation Center 와 로봇 실행 경로에 잇는다.
- **목표:** 사용자가 보는 화면과 실제 실행 경로에서, 모델이 학습·판독 때와 똑같이 돌게 한다.
- **KPI**
  - 서버 판독과 Operation Center 실행의 값 차이(실현·roll·골반이 판정 잡음 안)
  - 무작위 조작 2 시간에서 처리 안 된 오류 0, 실시간 비 0.99 이상
  - 새 최선본이 통과한 뒤 화면에 오르기까지 걸린 시간
  - 실행 고리의 지연(p50·p99)이 학습에 쓴 지연 범위 안에 있는가
  - 내보낸 모델과 원본의 출력 차
- **동작 방식**
  - 모델과 생성기는 고치지 않고 감싼다. 올리기 전에 서버 판독과 같은 입력으로 대조한다.
  - 공용 명령 규약을 그대로 쓴다. 참조가 끊기면 서기로 돌아가게 한다.
  - 로봇 접속과 배포는 사용자가 허락한 때에만 한다.
- **입력:** 판별을 통과한 병합 저장본, 생성기의 실시간 진입점, 명령 규약
- **출력:** Operation Center 의 모델 목록, 내보낸 모델과 고리 사양(주기·지연·끊김 때 동작), 대조표
- **하지 않는 일:** 학습, 참조 설계, 품질 판정
