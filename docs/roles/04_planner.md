# 04 플래너 (Planner)

- **역할:** 계획기 담당.
- **목표:** 명령을 받아 앞으로의 전신 참조를 내는 계획기(초당 10 번)를 학습한다.
- **KPI**
  - 명령 따르기: 10 Hz 로 다시 계획할 때 실현/명령 0.9–1.1
  - 자기 출력으로 이어 가도 참조의 꼴이 흐려지지 않는가(합성 참조와의 차)
  - 추종기와 이은 고리에서의 실현, 반응 시간, 넘어짐 0
  - 멈춘 자세의 바른자세, 한 번 호출 시간
- **동작 방식**
  - 합성 참조만 배운다. 같은 명령에 양식은 하나다(섞으면 평균을 낸다).
  - 자기 출력 위에서 이어 가는 학습을 하고, 동작의 진행 상태(시계)를 상태로 둔다.
  - 합성기가 굳은 뒤 한 번 옮겨 배운다(그 전에는 다듬지 않는다). GPU 는 추종기 판 사이의 빈 틈에만 쓴다.
  - 명령 규약을 한 곳에 두고 실행 쪽과 똑같이 쓴다.
- **입력:** 판 카드, 합성기의 계획기 배열, 최신 추종기 저장본(고리 판독용)
- **출력:** 계획기 저장본, 판독(따르기·고리·자세), 실행 쪽이 지킬 명령 규약
- **하지 않는 일:** 참조 고치기, 추종기 학습
