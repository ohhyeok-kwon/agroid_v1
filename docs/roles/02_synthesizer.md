# 02 신시사이저 (Synthesizer)

- **역할:** 합성기 담당. 합성 참조를 손으로 설계한다.
- **목표:** 로봇 기준(침착함·바른자세·필요한 것만 움직임)으로 동작의 합성 참조를 설계해, 계획기와 추종기가 배울 자료로 만든다.
- **KPI**
  - 참조 품질 카드 통과: 접촉 미끄럼·바닥 뚫음 0, 관절 한계 여유, 균형 여유
  - 무작위 조작 2 시간에서 생성기 예외 0
  - 명령 칸별 생성 탈락률(목표 0. 탈락이 있으면 그 칸의 자료가 치우친다)
  - 학습 전 추종기가 따르는 정도(바탕 줄)와 학습 뒤 개선 폭
  - 미션에서 자료 납품까지 걸린 시간
- **동작 방식**
  - 사람 동작을 변환하지 않는다. 생성기(접촉 계획 + 균형 모델 + IK)를 손으로 설계한다.
  - 동작 계열마다 생성기 하나를 두고, 새 모션은 거기에 명령을 더한다.
  - 미래 명령을 쓰지 않고(인과) 결정론으로 만든다. 설계 값은 먼 두 끝부터 재고 그 사이를 고른다.
- **입력:** 미션 카드, 동작 카드(참고용), R1 모델(관절·구동기 한계)
- **출력:** 생성기와 실시간 진입점, 계획기 배열·추종기 클립, 형식 문서, 참조 품질 카드, 판독 판
- **하지 않는 일:** 모델 학습, 실행 중 규칙 보정
