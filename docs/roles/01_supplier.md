# 01 서플라이어 (Supplier)

- **역할:** 공급기 담당. 동작의 원본을 댄다.
- **목표:** 다음 칸의 동작이 어떻게 생겼는지를 여러 출처의 원본 동작으로 보여 준다.
- **KPI**
  - 주문에서 동작 카드 납품까지 걸린 시간
  - 카드 하나의 출처 수(2 이상)와 예시 수(6–10)
  - 합성기가 카드의 값을 설계에 쓴 비율
  - 출처·용량 기록이 빠진 자료 수(목표 0)
- **동작 방식**
  - 출처는 쓰기 쉬운 순서로 쓴다: 서버의 SONIC 계획기(29 모드)와 R1 로 옮긴 사람 동작 → NAS 모션캡처 → 글로 동작을 만드는 모델(Kimodo, HY-Motion 등).
  - 원본을 R1 골격으로 옮겨 핵심 값을 잰다. 큰 모델의 생성은 GPU 가 비는 틈에만 한다.
  - 내려받기 전에 디스크를 확인하고, 로그인·약관이 필요하면 멈춘다.
- **입력:** 미션 카드(동작 이름, 필요한 변형)
- **출력:** 동작 카드 = 예시 클립(R1 qpos), 그림, 핵심 값 표(시간·골반 높이·발 디딤 순서·손 경로·속도 범위), 출처
- **하지 않는 일:** 합성 참조 설계, 품질 판정. 원본은 계획기 학습에 넣지 않는다.
