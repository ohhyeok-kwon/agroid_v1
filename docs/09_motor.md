# 모터 스펙·제어

확인: 2026-11-07. 제조사는 [Unitree Robotics](https://github.com/unitreerobotics/.github/blob/main/profile/README.md)의 자체 조인트 계열이다.
**현재 R1 각 관절의 정확한 모터 SKU·제조 리비전은 미확정이다.** 백업에 모델 라벨/BOM이 없고 실기 수신 데이터만으로 SKU를 확정할 수 없다.
[R1 공식 사양](https://www.unitree.com/R1/)은 저관성 내전형 PMSM·이중/단일 엔코더를 명시하지만 관절별 모터 모델·정격토크는 공개하지 않는다.

아래는 관련 부품의 [제조사 자체 스펙시트 IM6014](https://www.unitree.com/IM6014/)다. R1 전체 관절의 확정 스펙으로 사용하지 않는다.

| 항목 | 공개 값 |
|---|---|
| 제품/모델 | IM6014 / N6014B-12.6 |
| 크기·질량 | Ø65×60mm, 535g |
| 전원·최대 선전류 | 24~75V, 40A |
| 감속비 | 38/3 ≈12.667:1 |
| 최대 토크(모터 한 개의 peak) | 토크와 속도가 같은 방향 31.7N·m, 반대 방향 34.4N·m — 무릎·발목 관절의 값이 아니다 |
| 무부하 최대 속도 | 60V에서 54.2rad/s; 다른 전압에 그대로 적용하지 않음 |
| 엔코더 | 회전자/출력축 이중 절대 엔코더, 회전자 15bit |
| 통신 | RS-485 다중 접속, 6/4Mbps, 8N1, ID 0~14 |
| 온도 보호 | 드라이버 >90°C, 권선 >130°C에서 정지/오류 |
| 미공개 | 연속 정격토크·토크상수·열 시정수·R1 관절별 설치표 |

공식 R1 URDF·MJCF의 관절 한계는 무릎·엉덩이 60N·m(18.8rad/s, 32:1 계열), 발목 50N·m(30rad/s, IM6014급 둘의 막대)이고 학습·평가 모델이 이 값을 쓴다. 순간 한계로 읽으며 지속 시간의 공개 근거는 없다.
[공식 R1-7a SDK](https://github.com/unitreerobotics/r1-7a_sdk)는 별도 7축 팔의 IM6014 계열 버스를 사용한다.
그 SDK의 관절군은 6010(32:1)·6014(38/3:1)·5010(16:1)이다. 현재 R1의 5축 팔과 동일 구성으로 단정하지 않는다.
현재 기체 설정 10/1의 내장 기본표에서 모터 26개·보조 IMU 슬롯 1개의 매핑을 복원했다.
기본 감속비는 32·12.6667이며 머리 관절 30은 214.3481이다. 설치 상태·영점·SKU는 실기 미확인이다.
머리 관절 30은 토크 스케일도 별도다. [제조사 초기화·복원 근거](07_mcu.md)를 참조한다.
7축 팔 영문 표의 `Torque Range`는 [중문 표](https://www.unitree.com/cn/R1-ARM/)의 라디안 범위와 같아 토크 수치로 채택하지 않는다.

| 제어 | 명세상 가능 여부·방법 |
|---|---|
| 위치 | 가능: 목표 q와 Kp/Kd를 지정하는 FOC 혼합 제어 |
| 속도 | 가능: Kp=0, 목표 dq와 Kd 사용; 독립 속도 모드가 아닌 이득 조합 |
| 토크 | 가능: Kp=Kd=0, τff 사용; 외력 실측값과 동일하지 않음 |
| 말단 힘 | 직접 F[N] 명령은 없음. 별도 패키지에서 자코비안·중력 보상·힘 피드백 필요 |

제어식 해석: `τcmd = τff + Kp(qd−q) + Kd(dqd−dq)`; [공식 저수준 인터페이스](https://github.com/unitreerobotics/unitree_sdk2/blob/main/example/r1/low_level/r1_ankle_swing_example.cpp).
R1 공식 표의 `About 2kg`는 팔 하중 설명이며 N·m 토크 스펙이 아니다.
위 가능 여부는 공개 명세·코드 기준이다. 프로젝트는 E2/F1 통신 초기화·상태 조회만 구현했으며 yaw 기준 탐색·좌표 보정은 미구현이다.
[바이트/단위 명세](10_motor_protocol.md) · [현재 수신 토픽](08_topic.md).

35슬롯 중 원본 R1에서 사용하지 않는 자리(장착 모터의 통신 실패를 뜻하지 않음):
| 슬롯 | 원본 이름 |
|---|---|
| 14 | WaistPitch |
| 20·21 | LeftWristPitch·LeftWristYaw |
| 27·28 | RightWristPitch·RightWristYaw |
| 31~34 | 원본 이름 없음·예비 |
앞의 5개 이름은 제조사 `robots/r1/JointIndex`에서 주석 처리돼 있다. 나머지 26개는 현재 기체 주소표에 있다.
